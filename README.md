DeepThink is an open-source web application that allows users to take multi-category personality tests and receive a personalized, empathetic analysis generated by AI. 

Most online personality tests harvest your data, require account sign-ups, or spam your email. **DeepThink is built differently.** It runs entirely in-memory using ephemeral server-side sessions. The moment a user views their results, their data is instantly and irreversibly destroyed.

---

## ✨ Features

- **8 Core Categories**: Social, Mental Wellbeing, Big Five (OCEAN), Emotional Intelligence, Stress & Burnout, Career, Relationship, and Self-Esteem.
- **Privacy-First Architecture**: Zero databases. Zero data persistence.
- **Dynamic Frontend Engine**: Smooth Single Page Application (SPA) experience powered by vanilla JavaScript and CSS glassmorphism (no heavy frontend frameworks required).
- **AI-Powered Insights**: Uses the `gemini-flash-latest` model to process demographics and answers into a warm, supportive analysis report.
- **Easily Extensible**: Add new questions just by modifying JSON files.

## 🚀 Quick Start

Follow these instructions to get a copy of the project up and running on your local machine for development and testing.

### Prerequisites

- Python 3.11 or higher
- A free Google Gemini API Key (Get one at [Google AI Studio](https://makersuite.google.com/app/apikey))

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/DeepThink.git
   cd DeepThink
   ```

2. **Create and activate a virtual environment**
   ```bash
   # On Windows:
   python -m venv venv
   .\venv\Scripts\activate

   # On macOS/Linux:
   python3 -m venv venv
   source venv/bin/activate
   ```

3. **Install the dependencies**
   ```bash
   pip install -r requirements.txt
   ```

4. **Environment Configuration**
   Rename the `.env.example` file to `.env` (or create a new `.env` file in the root directory) and add your secret keys:
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   FLASK_SECRET_KEY=generate_a_random_secret_string
   ```

5. **Run the app**
   ```bash
   python app.py
   ```
   Open your browser and navigate to `http://127.0.0.1:5000`

## 🛠️ How to Customize

Want to add your own questions or modify existing ones? You don't need to touch the code!

1. Navigate to the `questions/` directory.
2. Open any of the category folders (e.g., `questions/social/`).
3. Edit the `q10.json` file to add or change the questions and their options. 
4. The frontend will automatically detect the changes and render them!

*Note: The system looks for `q30.json`, then `q20.json`, then `q10.json` automatically. To unlock longer tests, simply create a `q20.json` file in a category folder.*
